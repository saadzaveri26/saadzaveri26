## 💼 Featured Projects

### 💻 1. SideKick — Next-Gen AI-Native Web Code Editor & Co-Pilot
> **Core Architecture:** Next.js, TypeScript, Convex, WebContainers, Inngest, Vercel AI SDK

*   **Business Problem:** Local development setup friction, lack of secure collaborative running environments, and weak contextual awareness in legacy web IDEs.
*   **The Solution:** An advanced, browser-based collaborative code editor running an entirely isolated Node.js environment natively inside the browser via WebContainers, backended by real-time sync.
*   **Production & Scalability Highlights:**
    *   **Agentic Orchestration:** Leveraged the Vercel AI SDK paired with Inngest background event-driven workflows to coordinate multi-model AI agents that write, test, debug, and execute code in real time.
    *   **Real-Time Sync Engine:** Built using Convex to provide sub-millisecond document synchronization and multi-user live-collaboration session consistency without server overhead bottlenecks.
    *   **Security Isolation:** Sandboxed runtime via WebContainers prevents execution breakouts, delivering native terminal experiences inside user browser instances.

### 🎙️ 2. AskRCOE — Multimodal Multilingual Institutional RAG Orchestrator
> **Core Architecture:** LangChain, LangGraph, FAISS, Python, Google Gemini, OpenRouter

*   **Business Problem:** Navigating large, unstructured institutional datasets with low lookup speeds, inaccurate cross-lingual search mechanisms, and rigid static architectures.
*   **The Solution:** An ultra-secure, multimodal AI assistant designed to extract, route, and index complex institutional documentation.
*   **Production & Scalability Highlights:**
    *   **Stateful Graph Pipelines:** Utilized LangGraph to engineer custom deterministic agent routing logic, achieving an outstanding **99.2% retrieval accuracy** rate.
    *   **Sub-Second Semantic Indexing:** Embedded and queried over 10,000 corporate/institutional compliance documents inside a highly tuned FAISS vector indexing space, minimizing cold-query latency to sub-second thresholds.
    *   **Multimodal Audio Engine:** Synthesized full bidirectional text-to-speech and voice-to-text audio processing pipelines with cross-lingual support spanning 15+ modern languages.

### 📊 3. Synapse-AI-Arena — Interactive Automated Machine Learning Arena
> **Core Architecture:** Scikit-Learn, XGBoost, Streamlit, Plotly, Altair, Pydeck

*   **Business Problem:** Time-consuming machine learning prototyping, slow validation loops, and disjointed rendering pipelines for massive spatial/structured datasets.
*   **The Solution:** A rapid prototyping data exploration platform automating heavy feature engineering, model training, and telemetry visualization.
*   **Production & Scalability Highlights:**
    *   **High-Throughput Rendering:** Seamlessly manages and renders high-density live streams of 100K+ data samples utilizing multi-dimensional rendering structures (Pydeck, Altair).
    *   **Automated Feature Engineering:** Implemented automatic data pipelines processing categorical encoding, normalization, and automated hyperparameter optimization across Scikit-Learn and XGBoost ensembles.
    *   **Cycle Acceleration:** Compressed the traditional multi-hour model testing cycle down to instant point-and-click operations inside a productionized Streamlit framework.
